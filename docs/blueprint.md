# **App Name**: CreatorBoost AI

## Core Features:

- Creative Strategy Suite: An AI-powered generator that uses reasoning as a tool to determine high-conversion titles, descriptions, and hashtags for cross-platform growth.
- Script Architecture Lab: Uses AI reasoning to act as a scripting tool, mapping out hooks, body content, and effective CTAs based on specified content goals.
- Dynamic Planning Calendar: An intelligent roadmap tool that plans out weekly or monthly content distribution based on audience analytics and creator niche.
- Live Visual Previewer: Real-time dashboard interface for previewing and editing AI-generated scripts and titles with high-fidelity glassmorphism elements.
- Secure Cloud Repository: Stores user profiles, historical generations, and custom brand settings using Firebase Firestore for persistent cloud-based access.
- Unified Identity Gate: Firebase-backed authentication supporting email and Google login for secure session management and data isolation.
- Project Vault: Dedicated space for users to save, organize, and export generated projects into accessible digital formats.

## Style Guidelines:

- Primary Color: Vibrant Indigo (#6366F1), selected for its contemporary energy and resonance with modern digital technology.
- Background Color: Ultra-Light Lavender-White (#F7F8FF), creating a clean, airy canvas that emphasizes clarity and speed.
- Accent Color: Azure Blue (#3B9AF0), an analogous hue that provides sophisticated contrast for interactive components and high-priority labels.
- A refined pairing of 'Poppins' for high-end headlines and 'Inter' for crisp, machined legibility across the functional UI and detailed text blocks.
- Modern SaaS dashboard structure utilizing a left sidebar with soft-corner containers and intensive use of whitespace to signify professional-grade tools.
- Utilizes smooth Framer Motion transitions with spring physics to give interactive elements a responsive, high-fidelity tactile feedback.
- Minimalist, thin-line stroke icons with subtle color gradients that reflect the premium visual identity of the 'PulseFlow' brand.
